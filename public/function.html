What the function is. x is time in minutes, with x = 0 now and x = −T the start of the window.
P(x) = p₀ + u·( m·x + Σₖ aₖ·sin(kπ(x+T)/T) ), where p₀ is the latest real price and u is 1 pip (FX) or about 1/10 000 of the price.
The straight line from the first to the last price is removed, and the rest is fitted to real bars by least squares on K sine waves. So P(0) is exactly the current price, and more harmonics follow the data more closely (the fit error is shown above).
B(x) is buy pressure from −1 (all selling) to +1 (all buying): 2·(buy volume ÷ volume) − 1 per bar, fitted the same way. On Kraken-backed FX pairs and Binance it uses real trades; on other FX pairs it uses up-ticks vs down-ticks.
The function describes the past window only. It is not a forecast; outside −T ≤ x ≤ 0 it is undefined.
